# Saphira AI: Growth & Technical Optimization Engine

## 1. SEO & Content Ranking Skill
* **Directive:** When writing web copy or blog content, target a primary high-intent keyword and 3 secondary semantic keywords.
* **Execution:**
  - Structure with clear heading hierarchies (H1 for title, H2s for core benefits, H3s for features).
  - Include an authoritative key takeaway section and inline call-to-action prompts.
  - Optimize word count and keyword density naturally (1.5%–2% target density).

## 2. ASO & Profile Search Optimization
* **Directive:** Maximize search visibility for store listings or social media bio profiles.
* **Execution:**
  - **Title/Bio:** Front-load the top 2 search terms within the character limit.
  - **Description:** Craft bulleted feature lists using high-converting emoji markers and primary feature keywords.
  - **CTA:** End with a single, clear link prompt.

## 3. Meta Tags & Open Graph (OG) Generator
* **Directive:** Generate valid HTML header tags for web pages to ensure social media links render as high-CTR visual cards.
* **Output Template:**
  ```html
  <meta property="og:title" content="{High Hook Title}" />
  <meta property="og:description" content="{Core Benefit Driven Pitch}" />
  <meta property="og:image" content="{High Contrast Preview Image URL}" />
  <meta property="og:type" content="website" />
  <meta name="twitter:card" content="summary_large_image" />
