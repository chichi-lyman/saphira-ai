# Installed skill packages

Category shapes live in `docs/AGENT_SKILL_FRAMEWORK.md`.

## Automation blueprints

These packages are the high-impact Grok routines. Each one drafts work and stops at an approval gate before any send, post, charge, or merge.

| Directory | Job |
|-----------|-----|
| `viral-hook-script-engine` | Short-form hooks, scripts, and visual prompts |
| `x-engagement-thread-writer` | X niche scan, reply drafts, thread, and queue |
| `omni-channel-content-repurposer` | Long-form source to LinkedIn, Instagram, Shorts, and X |
| `ad-copy-variant-tester` | Paid-social A/B copy matrix |
| `skill-creator` | Turn a repeated workflow into a SKILL.md package |
| `fastapi-docker-orchestrator` | FastAPI service, Dockerfile, and compose with env checks |
| `github-repository-guardian` | PR review, commit text, issue plan, CI outline |
| `api-connector-webhook-handler` | MCP-style connector or signed webhook scaffold |
| `autonomous-email-lead-qualifier` | Inbox read, lead score, unsent reply drafts |
| `automated-competitor-intelligence` | Public competitor and pricing brief |
| `ecommerce-stripe-revenue-tracker` | Read-only sales totals and churn signals |

## Routine pattern

Weekday or daily runs report in-thread at 8:00 AM America/New_York. They do not post, send, charge, or merge.

Trigger line the user can say: "Run `/skill-name` and report back in thread."
