## Goal
Make Saphira visible and interactive across every platform so the public experiences her as their personal AI assistant.

## Content Pillars (use Chelsea’s face + voice)
1. **Demo** – Show Saphira executing real tasks while Chelsea talks to camera.
2. **Personality** – Warm, direct, slightly playful replies that match the source videos.
3. **Monetization / Growth** – “Download Saphira AI to help me monetize” style CTAs.
4. **Community** – Shout-outs, red-flag talks, DM-me-growth hooks.

## Platform Mapping
| Platform        | Format              | CTA                          |
|-----------------|---------------------|------------------------------|
| TikTok          | 9–15 s Reels        | “Get Saphira – link in bio”  |
| Instagram Reels | Same as TikTok      | Link in bio / Story sticker  |
| YouTube Shorts  | Vertical            | Subscribe + description link  |
| Facebook        | Reels + Page posts  | Message Saphira / Visit site |
| LinkedIn        | Short professional  | “Try the live demo”          |
