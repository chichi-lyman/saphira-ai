## 1. Choice Mapper — decision paralysis

**Neurological failure point:** Cognitive overload and attentional blindness. Working memory saturates; anxiety loops; emotional intensity is mistaken for logical risk.

**How it solves it:** Accepts chaotic mind-dumps (voice, rants, half-formed thoughts, hard numbers)—not rigid pro/con spreadsheets.

**Mechanism**
1. **Structural filter** — parse input; extract core variables.
2. **Separate layers** — objective facts (salary, commute) vs subjective fears (change, imposter syndrome).
3. **Ripple mapping** — show hidden cause/effect (e.g. +income vs −10h leisure → gym loss → energy −30% from historical patterns).

**Daily impact:** Paralysis reduced through **clarity**, not prescription. The user still chooses; the map holds the chaos.

**Pipeline:** `[Chaotic Mind-Dump] → [Extract Core Variables] → [Isolate Facts vs Emotions] → [Visualize Ripple Effects]`

---

## 2. Crisis Synthesizer — sudden multi-shock chaos

**Neurological failure point:** Tunnel vision and adaptive stress. Cortisol impairs prefrontal planning exactly when long-term financial logic is needed.

**How it solves it:** Calm emergency triage coordinator; multi-modal intake (bill photos, bank screenshots, quotes).

**Mechanism**
1. **Cross-disciplinary risk** — physical degradation (mold risk, engine damage) vs legal/financial penalties.
2. **Urgency ordering** — what must be fixed now vs what can safely wait.
3. **30-Day path** — pay order, negotiation script stubs, DIY vs pro, avoid panic products (e.g. payday loans).

**Daily impact:** Objective buffer against reactive choices when the user cannot think straight.

**Pipeline:** `[Emergency Intakes] → [Cross-Reference Risk Thresholds] → [Dynamic Financial Triage] → [30-Day Action Path]`

**Policy:** Informational only; no autonomous payments or medical/legal authority.

---

## 3. Energy Tracker — executive dysfunction & burnout

**Neurological failure point:** Task initiation failure and dopamine scarcity. Rigid calendars assume constant capacity; high-load labels trigger avoidance and guilt.

**How it solves it:** Replace time-slot productivity with a **biometric-energy framework**.

**Mechanism**
1. **Cognitive load tagging** — Executive Function Cost, Physical Friction, Dopamine Velocity per task.
2. **State calibration** — user declares capacity (e.g. 10% brainpower).
3. **Micro-step slicing** — hide high-load goals; isolate one friction-free action that matches capacity.

**Daily impact:** Momentum without draining residual battery; guilt replaced by smallest viable next step.

**Pipeline:** `[Biological State] → [Filter High-Load Tasks] → [Isolate Low-Friction Micro-Steps] → [Momentum Unblocked]`

---

## 4. Symptom Detective — chronic patterns & habits

**Neurological failure point:** Signal noise and retrospective bias. Humans mis-attribute triggers; short clinical visits cannot untangle multi-week webs.

**How it solves it:** Passive pattern engine—casual notes, not meticulous journals.

**Mechanism**
1. **Asynchronous ingestion** — unstructured texts when symptoms appear.
2. **Multi-stream fusion** — notes + wearables (sleep, HRV, steps) + optional environment.
3. **Time-delayed correlation** — windows (e.g. 24–72h) for non-obvious co-occurrence.
4. **Micro-experiment** — one low-effort test for the next week.

**Daily impact:** Data-backed hypotheses and leverage—not diagnosis.

**Pipeline:** `[Casual Notes] + [Passive Wearable Logs] → [Time-Series Correlation] → [Isolate Hidden Triggers]`

**Policy:** Not medical advice; consent for biometrics; hypotheses labeled exploratory.
